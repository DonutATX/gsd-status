Wire the VS Code extension packaging toolchain so the extension builds into a clean, installable `.vsix`.

Purpose: Phase 6's core deliverable is a distributable extension. Without a working `package` script and a correctly-scoped `.vscodeignore`, the `.vsix` either fails to build (`vsce` not installed) or ships internal tooling and compiled test code.

</objective>
