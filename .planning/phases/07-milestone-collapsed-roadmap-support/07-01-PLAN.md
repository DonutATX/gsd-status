<objective>
Extend the ROADMAP.md parser so a milestone-collapsed roadmap (no `### Phase N:`
detail headers — `<details>` blocks plus a `## Progress` table) parses to a
non-empty, milestone-grouped phase list, while expanded roadmaps parse unchanged.

Purpose: The extension currently shows "GSD: Error" on any multi-milestone GSD
project because `parseRoadmap` returns zero phases for collapsed roadmaps. This
plan closes PARS-06 and PARS-07 — the parser-tier half of the gap.

Output: Extended `types.ts`, a two-path `parseRoadmap` with a `parseCollapsedRoadmap`
helper and `## Milestones` parser, a new collapsed-roadmap test fixture, and a
collapsed-roadmap `describe` block in `roadmap.test.ts`.
</objective>
