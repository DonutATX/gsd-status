<objective>
Restructure the TreeView so milestones are top-level nodes with their phases
nested underneath, with the active milestone expanded by default and the active
phase still visually distinguished — falling back to the existing flat phase
layout when the roadmap has no milestone grouping.

Purpose: Closes PANL-08, the TreeView half of the Phase 7 gap. Depends on
Plan 01, which adds `RoadmapData.milestones` and `RoadmapPhase.milestoneLabel`.

Output: A `milestone` variant on `GsdTreeItem`, a milestone-aware `provider.ts`
(`_getRootChildren`, `getChildren`, `getTreeItem`, a `slugify` helper), and a
milestone-grouped tree `describe` block in `provider.test.ts`.
</objective>
