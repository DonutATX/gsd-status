# Phase 4 — UI Design Contract

> Visual and interaction contract for Phase 4: Tooltip, Commands + Configuration.
> Generated by gsd-ui-researcher. This phase has no web UI, no CSS, and no custom rendering.
> All "UI" surfaces are VS Code native: a MarkdownString tooltip, Command Palette entries,
> and contributes.configuration settings. VS Code's active theme is the design system.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — VS Code native API only |
| Preset | not applicable |
| Component library | VS Code Extension API (vscode.MarkdownString, StatusBarItem, commands) |
| Icon library | VS Code built-in Codicons ($(pulse), $(error), $(info), $(calendar), $(clock)) |

shadcn gate: not applicable. Tech stack is TypeScript + VS Code Extension API — no React, no Vite, no web renderer.

## Spacing Scale

Not applicable. Extension does not render custom CSS. Tooltip layout is controlled by MarkdownString
line breaks and horizontal rules, not pixel spacing.

MarkdownString structural rules (used in place of spacing tokens):

| Pattern | Usage |
|---------|-------|
| `\n\n` (blank line) | Separates logical sections within the tooltip |
| `---` (HR) | Separates the header block from the last-entry block |
| Single `\n` | Separates a label line from its value line within a section |

## Typography

Not applicable. Extension does not set font sizes or weights. VS Code theme governs all typography.

MarkdownString emphasis rules (used in place of typography tokens):

| Construct | Usage |

## Tooltip Contract (STAT-03)

The tooltip is a `vscode.MarkdownString` with `isTrusted: false` (no command URIs needed).

### ok state — full tooltip

```
**GSD**

**Milestone:** {milestoneLabel ?? projectName ?? "GSD"}
**Phase:** {active.number}: {active.name}
**Goal:** {active.goal ?? "(no goal defined)"}

---

**Last Entry**
_{relative time}_ — `{absolute ISO timestamp}`
{lastEntry.text}
```

Rules:
- `milestoneLabel` is used when present; fall back to `projectName`; fall back to the literal string "GSD".
- "active phase" is the first `RoadmapPhase` where `done === false`.
- If all phases are done, Phase line reads: "All phases complete".
- `active.goal` is shown in full — no truncation.
- Relative time format: use a simple hand-rolled helper (no date library). Buckets: "just now" (<60s), "Nm ago" (<60m), "Nh ago" (<24h), "N days ago" (>=24h). Source: CONTEXT.md.
- Absolute timestamp: ISO 8601 string from `StateData.lastUpdated` or `StateEntry.timestamp`.
- If `lastEntry` is absent: omit the "Last Entry" section entirely (do not show a blank or "(none)").

### error state — error tooltip

```
**GSD — Parse Error**

{state.message}
```

Rules:
- Render the actual `state.message` string, not a generic fallback. Source: CONTEXT.md.
- `isTrusted: false` still applies — do not render raw error text as trusted HTML.

### no-project state

Tooltip: `undefined` (no tooltip shown). Status bar text "GSD: No project" is self-explanatory.

## Command Palette Contract (CMD-01 through CMD-04)

All commands are registered in `package.json` `contributes.commands` and wired in `activate()`.
All appear in the Command Palette under the "GSD" category.

| Command ID | Palette Title | Category | Behavior |
|------------|---------------|----------|----------|
| `gsd.refresh` | `Refresh` | `GSD` | Calls `controller.refresh()`. No toast on success — status bar updates visibly. |
| `gsd.openRoadmap` | `Open Roadmap` | `GSD` | Opens `.planning/ROADMAP.md` in an editor tab. If absent: shows info message (see Copywriting). |
| `gsd.openState` | `Open State` | `GSD` | Opens `.planning/STATE.md` in an editor tab. If absent: shows info message (see Copywriting). |

Palette display format (what the user sees): `GSD: Refresh`, `GSD: Open Roadmap`, `GSD: Open State`.

No keyboard shortcuts are assigned in Phase 4.

No command icons are assigned (icon-only toolbar actions are Phase 5 scope).

## Configuration Contract (CFG-01 through CFG-03)

Declared in `package.json` `contributes.configuration`. Both settings use `"scope": "window"`.

### gsd.refreshIntervalSeconds

| Property | Value |
|----------|-------|
| Type | `number` |
| Default | `30` |
| Minimum | `5` |
| Description | "Interval in seconds between automatic GSD file refreshes." |
| Live reload | Yes — `onDidChangeConfiguration` listener restarts the timer via `controller.setRefreshInterval(seconds)` without a window reload. |
| Guard | `package.json` `minimum: 5` + defensive clamp in `StateController.setRefreshInterval()`: `Math.max(5, value)`. |

### gsd.recentActivityCount

| Property | Value |
|----------|-------|
| Type | `number` |
| Default | `5` |
| Minimum | `1` |
| Description | "Number of recent STATE.md entries to surface in the GSD side panel." |
| Live reload | Yes — `onDidChangeConfiguration` listener fires; value is stored for Phase 5 panel consumption. |
| Guard | `package.json` `minimum: 1` + defensive clamp: `Math.max(1, value)`. |
| Phase 4 usage | Config entry is declared now; consumed by Phase 5 panel. Phase 4 only stores/exposes the value. |
