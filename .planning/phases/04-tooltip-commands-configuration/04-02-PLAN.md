## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user → Command Palette | A developer invokes GSD commands; command callbacks act on the workspace's `.planning/` directory only |
| disk → extension | `openTextDocument` reads files whose existence is not guaranteed |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-03 | Denial of Service | openFile helper | mitigate | Wrap `openTextDocument` in try/catch so a missing file produces an info message, not an unhandled rejection that destabilizes the extension host |
| T-04-04 | Elevation of Privilege | command callbacks | accept | Commands only read files inside the open workspace's `.planning/` dir and never write; read-only by design (PROJECT.md constraint) |
| T-04-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs in this plan — zero new dependencies; nothing to verify |
</threat_model>
