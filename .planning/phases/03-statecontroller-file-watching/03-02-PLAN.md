<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| disk → FileSystemWatcher → StateController | file-change events and file content cross from the OS into the extension |
| extension lifecycle → StatusBarItem | late timer/watcher callbacks may fire during deactivation |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-04 | Tampering | watcher glob built with path.join (Windows backslash bug) | mitigate | Use `vscode.RelativePattern` with the brace glob — never `path.join` (WAT-01, RESEARCH.md anti-pattern) |
| T-03-05 | Denial of Service | 4–12 OS events per save causing repeated refresh / CPU spike | mitigate | 300ms debounce coalesces events into one refresh (WAT-02) |
| T-03-06 | Denial of Service | timer/watcher callback touching a disposed StatusBarItem after deactivate | mitigate | `lifecycle.disposed` guard at the top of the onStateChanged callback (RESEARCH.md Pitfall 5); StateController.dispose() disposes watcher → timer → emitter in order |
| T-03-SC | Tampering | npm/pip/cargo installs | mitigate | N/A — no packages installed this phase (RESEARCH.md Package Legitimacy Audit) |
</threat_model>
