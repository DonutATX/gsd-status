# GSD Status

Live GSD workflow state — milestone, phase, and recent activity — in your VS Code status bar.

Phase 6 will expand this README with install instructions, configuration, and a screenshot.

## Scripts

- `npm run compile` — Compile TypeScript to `out/`.
- `npm run watch` — Compile in watch mode.
- `npm run package:vsix` — Package the extension as a `.vsix`. **Requires Phase 6 install** of `@vscode/vsce` as a devDependency; until then this script will fail with `vsce: command not found`.
